# Placement Application Tracker

A cloud-based Spring Boot REST API project to track placement applications.

## Features
- Add placement applications
- View all applications
- Update application status
- Delete applications

## Technologies Used
- Java
- Spring Boot
- PostgreSQL
- Maven
- Postman
- GitHub

## API Endpoints
- POST /applications
- GET /applications
- PUT /applications/{id}
- DELETE /applications/{id}

## Database
PostgreSQL database: `placementdb`
